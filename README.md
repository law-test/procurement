# 공공조달관리사 수험·학습·취업 지도

2026년 신설 국가자격 **공공조달관리사** 수험생을 위한 민간 정보 사이트. GitHub Pages 정적 사이트로 운영한다.

사이트: https://jodal.pro/ (GitHub Pages)

## 2026-09-16 현재 화면

- 첫 화면은 두 역할의 분기 스토리 `story/`에서 시작한다. 미니게임은 그 아래에서 플레이한다.
- `rank/`: 게임별 최고점·누적점수, 주간/전체, 닉네임 참여, 공개 기록 링크, 공개 중단·본인 활동 삭제.
- `news/`, `board/`, `review/`: 뉴스 원문 링크 공유, 자유게시판·댓글, 교재·강의·사이트 17개 대상의 실제 이용 후기. 내용만으로 게시 가능하며 제목은 본문 앞부분, 새 별명은 무작위 조합으로 자동 작성한다. 이름·제목은 선택 입력이고, 별명 다시 뽑기를 제공한다. 게시 체크박스 없이 올리기 버튼으로 공개한다.
- `assets/rank-config.js`에는 Supabase **publishable key만** 둔다. 서버 비밀키를 넣지 않는다. 전용 `jp_rank_*`, `jp_comm_*` 표·함수는 기존 서비스 자료와 분리되어 있다.
- 서버 초기 적용 순서는 `supabase/ranking.sql` → `supabase/community.sql`. 게임 규칙 변경 시 `python tools/build_ranking_seed.py`로 검증 규칙을 다시 생성하고 서버에도 같은 버전을 적용한다.
- 본인 관리값은 `jodal.rank.identity.v1`, 완료 기록은 `jodal.rank.record.<UUID>`에 보관한다. 공개 순위에 참여한 경우에만 게임 완료 기록을 전송하며, 게시판·후기는 별도로 공개 등록한다. 관리키를 잃으면 기기 간 복구할 수 없다.
- 미니게임은 하루·모드별 최고 환산점수, 스토리는 역할·엔딩별 최고 환산점수를 누적한다. 서버는 경로·답변을 검증해 재계산하며 실제 플레이 시간이나 동일인 여부를 인증하지 않는다.
- 글·댓글·후기는 작성자 자신의 브라우저에서 수정·삭제한다. 서버 활동 모두 삭제는 그 작성자의 순위·글·댓글·후기를 함께 삭제한다. 다른 작성자의 원글 아래 남긴 댓글 중 작성자 본인 댓글만 삭제하며, 본인의 원글을 지우면 그 글에 달린 댓글도 삭제된다.

### 이전 미니게임 구성의 유지 사항

- 홈에서 콤보 챌린지, 조달 미션, 개념 짝맞추기를 바로 플레이한다.
- 메뉴는 게임·복습·자료·취업·활용 네 개다. 학습계획·개념 사전·기존 연습은 자료 모음에서도 찾는다.
- `data/learning-reviewed.json`: 공식 근거와 연결한 독립 작성 6 atom·12문항. 게임과 `learn/`이 같은 판단을 사용한다. 전체 시험 범위를 대표하지 않는다.
- `data/review-policy.json`: 정답 노출 4개를 제외한다. 기존 439개는 재검수 중인 개념 연습 자료이며 실전 승인 문항은 현재 0개다. 30·20·30개 승인 문항이 확보되기 전 80문항 기능을 열지 않는다.
- `jodal.games.v1`은 기존 개인 게임 기록, `ppm.srs.v1`은 기존 복습 기록이다. 이 저장값 자체를 업로드하지 않는다. 공개 참여 후 새로 남긴 검증 가능한 완료 기록은 별도 전송한다.

## 현재 화면 갱신

공식 원문을 대조하고 독립 작성·정답·선지별 이유를 검토한 뒤 `data/learning-reviewed.json`을 갱신한다. 법정 금액·기간·비율은 임의로 바꾸지 않는다.

```powershell
python tools/build_reviewed_learning.py
python tools/refresh_experience.py
```

이 명령은 읽기 페이지·자료 모음과 공통 메뉴를 갱신한다. 문항 자동 변형기는 아니다. 현재 홈은 `index.html`을 직접 편집하며 갱신 도구가 스토리·순위·커뮤니티 홈을 덮어쓰지 않는다. 이전 생성기는 구형 화면·무검수 문항의 재공개를 막기 위해 중단돼 있다.

## 구조

```
index.html        홈
exam/             시험·접수 안내
about/            소개·정정 안내
assets/           공통 CSS·JS (site.css, site.js)
data/             검수한 새 게임 자료·기존 개념 자료·검수 정책(JSON)
learn/            게임과 연결한 6개 핵심 판단
library/          자료·학습계획·개념 사전 모음
tools/            현재 화면 갱신 도구 및 실행 중단된 과거 생성기
```

## 원칙

- 시험 제도·일정·출제기준은 Q-Net과 관계기관의 공식 공고를 우선한다. 교재로 시험범위를 단정하지 않는다.
- 원문 사실 / 자체 해석 / 학습용 가정을 구분해 표시하고, 확인하지 못한 항목은 미확인으로 남긴다.
- 공식 예제문제의 원문·선지·정답 매핑과 상업용 수험서 파생 데이터는 공개하지 않는다. 공개판은 자체 문장으로 재작성한 것만 쓴다(`publish_scope`).
- 검수를 통과한 항목부터 공개한다. 준비되지 않은 화면을 목차만 먼저 열지 않는다.
- 자격 취득이 가점·취업·소득을 보장한다고 쓰지 않는다.

## 기존 데이터 이력

```
atom 원장 xlsx  →  tools/build_atoms.py  →  data/*.json  →  정적 화면
```

위 파이프라인은 과거 설계 기록이다. 현재 게임 자료는 독립 검수 묶음을 사용한다. 상업용 교재 연결 정보나 원문을 새 공개 데이터에 합치지 않는다. 기존 자료 전체가 재검수된 것으로 표현하지 않는다.
