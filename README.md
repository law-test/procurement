# 공공조달관리사 수험·학습·취업 지도

2026년 신설 국가자격 **공공조달관리사** 수험생을 위한 민간 정보 사이트. GitHub Pages 정적 사이트로 운영한다.

사이트: https://jodal.pro/ (GitHub Pages)

## 2026-09-16 현재 화면

- 홈에서 콤보 챌린지, 조달 미션, 개념 짝맞추기를 바로 플레이한다.
- 메뉴는 게임·복습·자료·취업·활용 네 개다. 학습계획·개념 사전·기존 연습은 자료 모음에서도 찾는다.
- `data/learning-reviewed.json`: 공식 근거와 연결한 독립 작성 6 atom·12문항. 게임과 `learn/`이 같은 판단을 사용한다. 전체 시험 범위를 대표하지 않는다.
- `data/review-policy.json`: 정답 노출 4개를 제외한다. 기존 439개는 재검수 중인 개념 연습 자료이며 실전 승인 문항은 현재 0개다. 30·20·30개 승인 문항이 확보되기 전 80문항 기능을 열지 않는다.
- `jodal.games.v1`은 개인 게임 기록, `ppm.srs.v1`은 기존 복습 기록이다. 서버에 자동 동기화하지 않는다.

## 현재 화면 갱신

공식 원문을 대조하고 독립 작성·정답·선지별 이유를 검토한 뒤 `data/learning-reviewed.json`을 갱신한다. 법정 금액·기간·비율은 임의로 바꾸지 않는다.

```powershell
python tools/build_reviewed_learning.py
python tools/refresh_experience.py
```

이 명령은 읽기 페이지·자료 모음·게임 홈과 공통 메뉴를 갱신한다. 문항 자동 변형기는 아니다. 홈 문구의 원본은 `tools/templates/game-home.html`이다. 이전 생성기는 구형 화면·무검수 문항의 재공개를 막기 위해 중단돼 있다.

## 구조

```
index.html        홈
exam/             시험·접수 안내
about/            소개·정정 안내
assets/           공통 CSS·JS (site.css, site.js)
data/             검수한 새 게임 자료·기존 개념 자료·검수 정책(JSON)
learn/            게임과 연결한 6개 핵심 판단
library/          자료·학습계획·개념 사전 모음
tools/            현재 화면 갱신 도구 및 실행 중단된 과거 생성기
```

## 원칙

- 시험 제도·일정·출제기준은 Q-Net과 관계기관의 공식 공고를 우선한다. 교재로 시험범위를 단정하지 않는다.
- 원문 사실 / 자체 해석 / 학습용 가정을 구분해 표시하고, 확인하지 못한 항목은 미확인으로 남긴다.
- 공식 예제문제의 원문·선지·정답 매핑과 상업용 수험서 파생 데이터는 공개하지 않는다. 공개판은 자체 문장으로 재작성한 것만 쓴다(`publish_scope`).
- 검수를 통과한 항목부터 공개한다. 준비되지 않은 화면을 목차만 먼저 열지 않는다.
- 자격 취득이 가점·취업·소득을 보장한다고 쓰지 않는다.

## 기존 데이터 이력

```
atom 원장 xlsx  →  tools/build_atoms.py  →  data/*.json  →  정적 화면
```

위 파이프라인은 과거 설계 기록이다. 현재 게임 자료는 독립 검수 묶음을 사용한다. 상업용 교재 연결 정보나 원문을 새 공개 데이터에 합치지 않는다. 기존 자료 전체가 재검수된 것으로 표현하지 않는다.
