# 학습 데이터와 화면 갱신 도구

2026-09-16부터 원장 기반 자동 생성기를 중단했다. 기존 소스는 과거 산출물의 경위를 확인할 수 있도록 보존한다. 소스 안의 과거 출제 비율·형식 설명은 현재 공개 정책이나 검수 완료 근거가 아니다.

## 현재 흐름

1. 원장·상업 교재·OCR 전사본과 작업 초안은 공개 저장소 밖에서 관리한다. 저장소 안에 불가피하게 두는 로컬 작업물은 `.gitignore`의 `_private/` 등 제외 경로를 이용하고, 강제 추가하거나 정적 배포에 포함하지 않는다. `.gitignore`는 접근 통제나 배포 필터가 아니다.
2. 공식 원자료를 직접 확인하고 atom·상황·선택지·해설을 독립 작성한다. 근거 URL·적용 조건·법령 기준일·변경 이력·선택지별 판정·검수 상태를 확인한다. 중요도나 기존 문항 연결 수만으로 공개 대상으로 승격하지 않는다.
3. 새 검수 데이터는 `data/learning-reviewed.json`, 기존 문항의 사용 제한은 `data/review-policy.json`에서 관리한다. 기존 자료를 보존하더라도 검수된 새 문항, 개념 확인용 후보, 보류 문항을 같은 실전모의 출제 풀로 합치지 않는다. 파일 이름에 reviewed가 들어간다는 사실만으로 검수가 완료되지는 않는다.
4. 현재 화면 갱신은 `tools/refresh_experience.py`를 확인하여 수행한다. 이 도구는 화면을 갱신하는 용도이며 원장 내용을 자동으로 공개 승인하거나 문항의 정답을 검수하는 도구가 아니다. 기존 `build_*.py`를 먼저 돌리는 단계는 없다.
5. 변경된 데이터·화면의 실제 동작, 보류 문항 제외, 출처 표시, 학습기록 연결과 배포 대상 파일을 확인한 뒤 검토된 변경만 공개한다. 서버 없는 단일 HTML 내보내기는 현재 지원하지 않는다.

## 실행을 중단한 기존 도구

| 도구 | 중단 이유 |
|---|---|
| `build_quiz.py` | 원장 내용을 검수 없이 `data/quiz.*.json`으로 출력한다. 자동 생성 문항의 정답 노출·제목 식별·조합 및 추적 문제가 확인됐다. |
| `build_pages.py` | 원장 본문·카드를 공개 경로로 출력하고 기존 학습 화면을 다시 만든다. |
| `build_ui.py` | 새 게임 홈과 검수 정책이 반영된 학습·모의시험 화면을 이전 템플릿으로 덮어쓴다. |
| `build_plan.py` | 최신 학습계획 화면과 날짜 처리의 변경을 덮어쓴다. |
| `build_links.py`, `build_legal.py`, `build_future.py`, `build_errata.py` | `build_pages.py`의 구형 공통 화면에 의존한다. 최신 화면을 보존하도록 새 갱신 흐름에 통합하기 전까지 중단한다. |
| `pack_standalone.py` | 원장 기반 카드·문항을 HTML에 일괄 삽입하며 현재 검수 정책과 새 학습 엔진을 완전하게 포함하지 않는다. |

위 9개 도구는 파일 읽기·가져오기·출력 전에 명시적인 오류 메시지와 실패 종료를 반환한다. 직접 실행과 Python 가져오기를 모두 차단하며, `PPM_OUT`, `PPM_BUILD`, `PPM_PACK` 변경으로 재활성화되지 않는다. 초안 출력 기능이나 공개 강제 실행 옵션은 제공하지 않는다.

다시 활용하려면 해당 생성기가 새 검수 정책을 준수하고 공개 데이터 및 화면을 덮어쓰지 않는지 먼저 수정·검토해야 한다. 중단문만 지워 실행하는 것은 현재 갱신 절차가 아니다.
