기록·개인정보 안내

게임은 가입 없이 이용합니다. 공개 순위나 게시판·후기는 직접 참여할 때만 서버에 기록합니다.

기기 안에 남는 기록

미니게임 점수·오답, 복습·학습계획, 스토리 선택 경로·엔딩, 공개 등록을 기다리는 완료 기록은 브라우저에 저장합니다. 사이트 데이터를 지우면 기기 기록이 사라집니다.

순위·커뮤니티에 참여할 때

항목목적·공개 범위
닉네임, 무작위 관리 식별값·관리키의 해시본인 활동 관리. 닉네임만 공개하며 관리키와 비공개 식별값은 공개하지 않습니다.
게임 종류·선택 내역·점수·엔딩·등록 시각점수를 다시 계산하고 중복을 막습니다. 공개 순위에는 닉네임·게임·점수·엔딩·달성일만 표시하며, 세부 선택 내역은 공개하지 않습니다.
게시글·뉴스 링크·별점·이용 후기직접 등록한 글과 후기, 닉네임, 작성일은 공개됩니다. 뉴스 원문은 복제하지 않고 링크와 직접 쓴 요약을 받습니다.

순위 참여 시 이 브라우저의 새 완료 기록과 이후 기록이 서버에 전송됩니다. 예전 최고점 숫자만 있는 기록은 가져오지 않습니다. 게시글·댓글·후기는 ‘올리기’를 누르면 공개되며, 공개 순위 참여와 별개입니다. 이름을 직접 쓰지 않아도 임의의 별명을 붙여 드리고, 제목을 비우면 본문 앞부분을 제목으로 사용합니다. 사용하던 별명은 유지하며 직접 바꾸거나 다시 뽑을 수 있습니다. 별명을 바꾸면 기존 공개 글과 후기에도 새 별명이 표시됩니다. 주민등록번호·주소·연락처나 타인의 개인정보를 글에 넣지 마세요.

저장·처리 장소

순위와 커뮤니티 데이터는 Supabase의 인도 뭄바이(ap-south-1) 서버에서 처리합니다. 전송 항목은 위 표의 활동 기록이며, 서비스 제공과 본인 활동 관리에 사용합니다. 삭제 요청 또는 이용자의 삭제까지 보관합니다. 웹페이지는 GitHub Pages, 도메인 연결은 Cloudflare를 이용합니다. 서버 제공업체의 기본 접속 로그 처리는 각 업체의 정책을 따릅니다.

공개 중단·삭제

순위 페이지의 공개 중단은 순위와 점수 공유 링크를 숨깁니다. 게시글·후기는 각 글에서 별도로 삭제할 수 있습니다. 내 서버 활동 모두 삭제를 선택하면 순위 기록·게시글·후기가 함께 삭제됩니다. 브라우저의 학습 진도와 스토리 진행은 유지됩니다.

이 브라우저에 보관한 관리키로 본인 활동을 관리합니다. 별도의 계정 로그인이나 다른 기기 복구는 제공하지 않습니다. 사이트 데이터를 지우기 전에 공개 중단 또는 서버 활동 삭제를 이용해 주세요. 관리키를 잃었으면 문의에 공개 글·기록 링크를 알려 주세요. 관리자 확인이 필요할 수 있습니다.

방문 통계

몇 사람이 다녀갔고 어느 화면을 많이 열었는지 집계로 봅니다. 집계 결과는 공개하지 않고 운영자만 열람 키로 확인합니다. 방문자 수와 화면별 조회수는 서버의 어느 경로로도 외부에 열려 있지 않습니다.

브라우저에 남기는 것은 무작위로 만든 값 하나입니다(jodal.did.v1). 쿠키가 아니라 브라우저 저장소에 넣고, 이름·연락처와 연결하지 않으며 광고에 쓰지도 제3자에게 넘기지도 않습니다. 브라우저·기기 특성을 조합해 사람을 알아내는 방식(핑거프린팅)은 쓰지 않습니다.

서버에 보내는 것은 열어 본 화면의 주소와, 브라우저를 새로 열었을 때 한 번만 브라우저·운영체제 이름, 모바일 여부, 화면 크기, 언어, 시간대입니다. IP 주소는 저장하지 않고 이용자별 열람 목록도 만들지 않습니다. 쌓이는 것은 날짜별 방문 브라우저 수와 화면별 열어 본 횟수라는 합계뿐이고, 이 합계도 비공개입니다.

구분되는 범위를 정확히 적으면, 같은 브라우저에서 다시 오면 같은 방문자로 셉니다. 브라우저 저장소를 지우거나 시크릿 창으로 오거나 다른 기기로 오면 새 방문자가 되고, 한 사람이 휴대전화와 PC로 오면 둘로 셉니다. 그래서 이 숫자는 사람 수가 아니라 브라우저 수입니다.

같은 화면을 몇 번 열었는지 외에 Cloudflare Web Analytics(쿠키·핑거프린팅 없음)를 함께 쓸 수 있도록 준비해 두었고, 켜면 들어온 경로와 대략적인 국가가 합계로 더해집니다.

내려받아 파일로 열어 본 화면과 개발용 주소(localhost)는 집계하지 않습니다.

보호 방식

HTTPS로 통신하고, 데이터 표를 직접 읽거나 쓰는 권한은 열지 않습니다. 공개 조회와 본인 관리 기능을 따로 두며 서버에는 관리키의 해시만 보관합니다. 관리키를 다른 사람에게 공유하지 마세요. 광고 목적의 기기 지문 수집은 하지 않습니다.
