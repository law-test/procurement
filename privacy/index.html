오류 신고

현재 오류 신고는 GitHub Issues에서 접수합니다. 신고 창에서 문제 내용·수정 제안·근거·선택 입력한 별명을 작성하면 GitHub의 새 이슈 화면으로 이동합니다. GitHub에서 제출을 완료해야 접수됩니다.

GitHub에 제출한 이슈는 공개됩니다. GitHub 계정명과 작성 내용이 다른 이용자에게 보일 수 있으므로 전화번호, 주소, 비밀번호 등 개인·민감정보를 쓰지 마세요. 이슈의 수정·삭제와 계정 정보 처리는 GitHub의 기능과 정책을 따릅니다.

웹페이지와 외부 자료 제공

사이트는 GitHub Pages에서 제공하며 글꼴은 jsDelivr에서 불러옵니다. 페이지나 글꼴을 요청할 때 IP 주소와 브라우저가 보내는 요청 정보가 해당 제공자에게 전달될 수 있습니다. 외부 링크를 열면 해당 사이트의 개인정보 정책이 적용됩니다.

현재 공개된 사이트 코드에는 별도 방문자 추적 스크립트나 기기 식별값 전송 기능이 연결되어 있지 않습니다. 향후 로그인·서버 저장 기능을 제공하면 수집 항목과 보관 방법을 이 화면에 안내하겠습니다.
