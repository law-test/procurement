적용조건 정산 조건에 관한 합의가 유효하게 성립한 경우 / 강행규정이나 계약조건이 달리 정하지 않은 경우

판단과 답안 요소 보기

적용조건 발주자 측의 불가피한 사정에 따른 해제·해지일 것 / 계약상대자에게 귀책사유가 없을 것

채무불이행과 관계없는 약정 해제권을 행사했다면 법정 채무불이행 손해배상이 당연히 뒤따르는가?

판단과 답안 요소 보기

판단과 답안 요소 보기

적용조건 재산권상의 분쟁이거나 당사자가 화해로 해결할 수 있는 비재산권상의 분쟁일 것 / 중재합의는 서면으로 할 것
